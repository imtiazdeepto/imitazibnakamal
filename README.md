# Imtiaz Ibna Kamal — Personal Portfolio

> Modern, high-performance multi-page personal portfolio tailored for a hybrid profile in **Software Engineering (Data Science)**, **Medical Computer Vision & Deep Learning**, and **Academic Research**.

Inspired by the iconic **Tomasz Gajda** dual-tone high-contrast design system, with academic publication management following **Jon Barron** and **al-folio** standards.

---

## 🌟 Key Highlights

- **Dual-Tone Angled Hero**: High-contrast split layout (light grey `#E2E2E2` left panel, pitch black `#0C0C0C` right panel) with tactile embossed action buttons and portrait framing.
- **Academic Research Hub**: Detailed presentation of 4 peer-reviewed & submitted papers (IEEE BECITHCON 2026, ICEEICT 2027), expandable abstracts, quantifiable metric badges (Dice score, ROC-AUC, parameter compression ratio), and 1-click **BibTeX citation copy**.
- **Production Systems Showcase**: Showcases full-stack ML applications (NeuroScan, MaritimeSafe, Polyp Segmentation) with FastAPI backend, Docker containers, Streamlit demos, and CPU-optimized inference.
- **Interactive Skills Matrix**: Categorized technical competencies spanning AI/ML, Vision, Systems Deployment, Scientific Frameworks, and Core CS.
- **Competitive Programming Hub**: Real-time stats and standings across Codeforces (Sentinel), CodeChef (2-Star), LeetCode (120+), and university algorithmic contests.
- **Curriculum Vitae Viewer**: Embedded PDF preview and instant download of the official CV.

---

## 📁 Multi-Page Structure

- `/` — **Home / Hero**: Tomasz Gajda angled split hero, impact metrics counters, and featured research/engineering highlights.
- `/about` — **About Me**: Academic background at Daffodil International University (CGPA 3.80/4.00), ACM Wing leadership & mentorship, honors and awards.
- `/research` — **Research & Publications**: Full publication showcase with interactive filter, expandable abstracts, and BibTeX citation modals.
- `/projects` — **Systems, Projects & Skills**: End-to-end full-stack AI systems, categorized skills matrix, and competitive programming track record.
- `/contact` — **Contact & CV**: Direct channels (Email, Phone, LinkedIn, GitHub, ResearchGate), interactive message form, and embedded PDF viewer.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Routing**: [React Router v6](https://reactrouter.com/) (Multi-page client routing with smooth scroll-to-top)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom geometric angled clip-paths & responsive typography
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (*Montserrat* & *Inter*)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation
```bash
# Clone repository
git clone https://github.com/imtiazdeepto/imitazibnakamal.git
cd imitazibnakamal

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
